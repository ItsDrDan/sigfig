# Sig Fig Sleuth: art to make in ChatGPT

**16 images total: 1 game logo + 15 badges.**

The lab instruments (rulers, cylinders, buret, thermometer, beaker, volumetric glassware, balances) are drawn by the game's code, because their markings have to be exact. Don't make those.

Until an image exists, the game shows a stand-in badge from the brand kit. When you drop a file in with the exact name below, the game uses it automatically. No code changes are needed.

## 1 game logo

| File | Size | Subject |
|---|---|---|
| `logo.png` in this repo, plus `assets/games/sigfig.webp` in the games repo (study hub card) | 1024 × 1024 (logo.png can be 512) | A cheerful magnifying glass (pink rim, navy handle) hovering over the number 0.0450. Inside the lens, the digits **450** glow green and the leading zeros fade to gray. A tiny detective hat sits on the rim. Name: Sig Fig Sleuth. |

Use the brand prompt from itsdrdan.github.io/games/brand and change only the Subject line.

## 15 badges

Make them on one sheet, like your 35-badge set: glossy cartoon style, transparent background, no text except the digits or symbols listed. Each badge is cut to **256 × 256 transparent WebP** and saved in `assets/` in this repo.
